# Release v1.5.0 — Trainable Everything, Higher-Order Autograd, and the Python Ecosystem

**Date:** 2026-10-17
**Tag:** `v1.5.0`
**Type:** Minor — large feature & correctness release

## Summary

v1.5.0 is the largest autograd and Python-ecosystem release since v1.0.0. Every
`nn.*` module that consumes a tensor is now **end-to-end differentiable**, the
autograd tape gained **higher-order (double-backward) support** across 40+ ops
plus forward/reverse-mode helpers, a PyTorch-style **functional namespace** was
added, **sparse tensors** landed, and **fourteen new pure-NumPy Python packages**
(`metrics`, `datasets`, `sampling`, `regularization`, `callbacks`, `linalg`,
`signal`, `graph`, `stats`, `structured_output`, `rag`, `agents`,
`observability`, `speculative`) were shipped with dedicated test suites.

A recurring theme of this release was finding and fixing silent correctness bugs
that made **models untrainable** while still producing numerically plausible
forward passes. Many of those bugs were caught by adding finite-difference and
exact-analytic gradient tests.

## What's New

### 1. Full differentiability — *every* `nn` module now trains

Prior to this release a significant number of `nn` modules used raw NumPy
forward paths and therefore produced **no autograd graph** — the model would
"run" but never learn. Each was rewritten to route through an `autograd_ops`
`Function` with an exact analytic adjoint:

- **Convolutions:** `Conv1d`, `Conv2d`, `Conv3d` (windowed-einsum grad-kernel,
  scatter-add grad-input; stride / padding / dilation aware).
- **Transposed convolutions:** `ConvTranspose1d/2d/3d` (exact adjoint of the
  scatter formulation).
- **Normalization:** `LayerNorm`, `RMSNorm`, `BatchNorm1d/2d/3d`, `GroupNorm`,
  `InstanceNorm1d/2d/3d`.
- **Embeddings:** `Embedding`, `EmbeddingBag` (sum / mean / max).
- **Pooling:** `MaxPool1d/2d/3d`, `AvgPool1d/2d/3d`, `AdaptiveAvgPool1d/2d/3d`,
  `AdaptiveMaxPool1d/2d/3d`, `MaxUnpool1d/2d/3d`, generic `Pooling1d/2d/3d`.
- **Resampling:** `Upsample` (nearest + generic N-D multilinear bilinear/trilinear
  with PyTorch `align_corners` semantics), `PixelShuffle`, `PixelUnshuffle`,
  `ChannelShuffle`.
- **Geometry / shape:** `Unfold`, `Fold`, differentiable `permute`, `Flatten`.
- **Metrics / heads:** `Bilinear`, `CosineSimilarity`, `PairwiseDistance`.
- **Activations:** `LeakyReLU`, `ELU`, `SELU`, `CELU`, `PReLU`, `RReLU`,
  `LogSigmoid`, `Softplus`, `Softsign`, `Hardswish`, `Hardtanh`, `Mish`,
  `Hardsigmoid`, `Hardshrink`, `Softshrink`, `Tanhshrink`, `Threshold`, `GLU`
  (notably `LogSigmoid` had an **incorrect derivative** that finite-difference
  tests caught).
- **Padding:** `ConstantPad` / `ZeroPad` / `ReflectionPad` / `ReplicationPad`
  (1d / 2d / 3d).
- **Dropout:** CPU path rewritten as a constant-mask multiply so gradients flow.

A repo-wide probe now reports **zero non-differentiable `nn` modules**.

### 2. Higher-order autograd + forward/reverse-mode helpers

- `Tensor.backward(create_graph=True)` and `grad(..., create_graph=True)` build a
  replayable graph so gradients themselves carry gradients.
- `create_graph` branches added for **40+ operations**, including `Add`, `Sub`,
  `Mul`, `Div`, `MatMul`, `Transpose`, `Sum`, `Mean`, `Relu`, `Sigmoid`, `Tanh`,
  `Sqrt`, `Exp`, `Log`, `Pow`, `Reshape`, `GetItem`, `Linear`, `Gelu`, `Silu`,
  `Softmax`, `LogSoftmax`, `LayerNorm`, `RMSNorm`, `Abs`, `Squeeze`, `Unsqueeze`,
  `Dropout`, `Cat`, `Stack`, `Neg`, `Conv1d`, and the loss functions
  (`MSELoss`, `CrossEntropyLoss`, `KLDivLoss`, `NLLLoss`, `BCELoss`,
  `BCEWithLogitsLoss`, `SmoothL1Loss`, `HuberLoss`).
- Verified with **exact Hessian reference tests** (e.g. KLDiv `2·t·tᵀ/n²`,
  CrossEntropy `2·c·cᵀ`, BCEWithLogits `(1/N)·xᵀ·diag(s(1−s))·x`,
  SmoothL1/Huber `H = 2·dS·dSᵀ + 2·S·diag(d²S)`).
- Added **`jvp`** (forward-mode: `J @ tangent`) and **`vjp`** (reverse-mode)
  helpers in `autograd`.

### 3. Functional namespace — `F.*`

A PyTorch-mirroring functional API (`sneppx_ALG.nn.functional`, exported as `F`)
with ~70 differentiable ops: activations, `linear` / `conv1d/2d/3d` /
`conv_transpose2d`, pooling (incl. adaptive), layer / rms / batch / group /
instance norm, padding, `flatten` / `unflatten`, `unfold` / `fold`, `embedding` /
`embedding_bag`, 14 losses, `interpolate`, `pixel_shuffle` / `channel_shuffle`,
`one_hot`, `pad_sequence`.

> `sx.functional` remains reserved for the pre-existing autograd functional
> module (JVP/VJP) — use the `F` alias.

### 4. Sparse tensors

New `sparse.py` with a canonical **COO** storage type (`SparseTensor`),
CSR / CSC / BSR layout constants and factories, dense interop, and ops:

- `sparse_mm` (sparse@dense, sparse@sparse, dense@dense)
- `sparse_addmm`, `sparse_sum`, `sparse_softmax`, `sparse_conv2d`
- `Tensor.to_sparse()` / `to_dense()` and `to_sparse_coo/csr/csc/bsr`
- `optim.SparseAdam` performs a real sparse step: moment buffers are read/written
  only at the grad's nonzero indices.

### 6. Optimizers

Added `Adam`, `NAdam`, `Rprop`, `ASGD`, `LBFGS`, and `SparseAdam` (sparse-aware)
alongside the existing SGD-family, plus full `param_groups` support.

### 7. Correctness & bug fixes

- **Scalar-first autograd:** `0.5 * x`, `1.0 - x`, `1.0 + x`, `2.0 / x` returned
  `requires_grad=True` but produced **no gradient**. `Function.apply` now records
  Tensor positions and realigns grads positionally.
- **Batched convolution (N>1):** `conv1d/2d/3d` scrambled outputs for batch
  sizes > 1 (a bogus reshape/transpose that was only correct at N=1).
- **`Conv` args:** Conv1d now adds bias with correct broadcasting.
- **`Cat.backward`** used `np.split(grad, sizes)` (wrong — treats sizes as
  indices); fixed to `np.cumsum(sizes)[:-1]`.
- **`RMSNorm.backward`** used the normalized input where the raw input was
  required (spurious `1/rms` factor).
- **`Mul.backward`** leaked a raw ndarray into `Tensor.*` (re-entering `forward`).
- **`Div.forward`** crashed on a scalar numerator; **`Pow.forward`** produced a
  shape-`(0,)` gradient when the exponent was a constant `Tensor`.
- **`MatMul`** double-backward for 1-D vectors (`xᵀw`) via Unsqueeze/Squeeze.
- **`MultiMarginLoss`** had a flipped margin sign
  (`margin − x_j + x_y` instead of `margin − x_y + x_j`).
- `load_state_dict(strict=True)` now raises on missing/unexpected keys and reports
  size mismatches; `register_buffer(persistent=False)` excludes buffers from
  `state_dict`.

## Upgrade Notes

- `nn` forward paths now build autograd graphs. If you relied on raw NumPy outputs
  from a layer (no `requires_grad`), wrap computations in
  `autograd.no_grad()`.
- `Tensor` stores **float32**; finite-difference checks should use `eps≈1e-3`.
- Scalar reductions (`sum()`, `mean()`, losses) return shape `(1,)`, not `0-d`.
- Install/upgrade: `pip install -U sneppx-alg`.
