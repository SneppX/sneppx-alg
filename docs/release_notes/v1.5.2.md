# v1.5.2 Maintenance and Security Follow-up

These notes document maintenance changes made against the v1.5.2 source line.
They do not declare every subsystem production-ready or independently audited.

## Python model configuration

- Kept `max_position_embeddings` and `max_seq_len` as separate configuration
  values during C/Python conversion.
- Restored the `num_hidden_layers` compatibility alias in both conversion
  directions.
- Corrected the Mistral RMS-normalization default and removed duplicate field
  declarations.
- Changed a shared test helper so failed conditions raise assertions instead
  of only printing diagnostics.

## CTM tooling

- Added `ctm_tools/py/ctm.py`, a standard-library repository scanner with text,
  JSON, CSV, and self-contained HTML dashboard output.
- Added streaming UTF-8 line counting, binary and symlink exclusion, generated
  directory exclusions, optional Git tracked/untracked counts, and a versioned
  JSON schema.
- Repaired the legacy LOC and summary wrappers and the directory-depth counter.
- Replaced a corrupted large-file script with a tested, symlink-safe scanner.
- Disabled building the incomplete legacy C CTM prototypes; they previously
  returned placeholder values on some platforms. The Python scanner is the
  supported implementation.
- Added unit tests and CI smoke tests for the scanner, compatibility scripts,
  and CTM CMake help target.

## Security hardening

- Replaced `rand()` / `srand()` in the advanced obfuscation module with the
  OS-backed `SNEPPX_random_bytes` interface for junk-pattern selection.
- Used OS randomness for instruction-order shuffling and fail-closed behavior
  if entropy retrieval fails.
- Hardened junk-code insertion bounds and validated the pattern count before
  indexing the fixed-size pattern array.
- Disabled unsafe bogus control-flow rewriting, TLS callback pointer mangling,
  anti-dump image mutation, and the placeholder whitebox AES implementation.
  These APIs now fail closed rather than modifying executable code or
  presenting non-cryptographic behavior as encryption.
- Added native regression tests for the disabled APIs and buffer-preservation
  guarantees.

**Important:** S2 remains experimental. IAT synchronization and other audit
findings remain open. The disabled features are not repaired implementations;
they must remain unavailable until safe, reversible, independently reviewed
designs exist.

## Post-quantum cryptography status

The PQC implementations remain experimental. The repository's ACVP harness
has partial ML-KEM coverage, while finalized FIPS ML-DSA and SLH-DSA valid
signature interoperability remains incomplete. No FIPS validation or
certification is claimed. See the [PQC interoperability report](../pqc_kat.md).

## Documentation website

- Repaired MkDocs asset-list indentation and YAML validation.
- Added CTM and security reports to site navigation.
- Corrected stale internal and external links and removed unsupported
  production-readiness claims.
- Added a strict MkDocs build and version-preserving GitHub Pages publishing
  workflow using `mike`. Existing `gh-pages` version history is preserved.
