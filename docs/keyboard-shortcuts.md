# Keyboard shortcuts

SneppX-Alg docs are fully keyboard-navigable. Press **`?`** anywhere to see
this list as an overlay.

## Global

| Shortcut | Action |
|----------|--------|
| `?` | Open / close the shortcuts overlay |
| `Ctrl` / `⌘` + `K` | Open the command palette |
| `/` | Focus the search box |
| `Esc` | Close the search, palette, or overlay |

## Command palette

| Shortcut | Action |
|----------|--------|
| `Ctrl` / `⌘` + `K` | Open |
| `↑` / `↓` | Move selection |
| `Enter` | Open the selected page or run the action |
| `Esc` | Close |

The palette searches every page in the navigation, plus quick actions:

- Toggle dark / light theme
- Open the playground
- Go to home
- Focus search
- Scroll to top

## Playground

| Shortcut | Action |
|----------|--------|
| `Ctrl` / `⌘` + `Enter` | Run the current snippet |
| `Tab` | Indent inside the editor |
| `Esc` | Blur the editor |

## Code blocks

Every Python block on the site has a **▶ Run** button. Click it to execute
the snippet in your browser with Pyodide (no installation required).
