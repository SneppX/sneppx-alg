Matmul visualizer

Matrix multiplication is a sum of row · column dot products. Hover any cell of C to see exactly which row of A and which column of B produced it — and the arithmetic term by term.

A 3×4
×
B 4×3
=
C 3×3

Why it matters for training

The same shape rule governs linear layers: an input (N, K) times a weight (K, N_out) produces (N, N_out). A shape mismatch like (N, C, L) @ (C,) fails instead of broadcasting — reshape the bias to (1, C, 1) first, as SNEPPX-Alg's Conv layers do.

import numpy as np
from SneppX_ALG import Tensor

x = Tensor(np.random.randn(2, 3).astype(np.float32))
w = Tensor(np.random.randn(3, 4).astype(np.float32))
print((x @ w).shape)          # (2, 4) — batch dimension preserved
