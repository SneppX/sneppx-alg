Perform Transport Noise Handshake.

Parameters
ts[out] Ts value.
prologue[in] Prologue value.
prologue_len[in] Prologue Len value.
handshake_msg[out] Handshake Msg value.
msg_len[out] Msg Len value.
Returns
0 on success, -1 on error.

The reference transport layer has no per-session Noise handshake state (no DH, chaining key or transcript), so it cannot establish a real Noise session. The previous implementation emitted 48 random bytes XORed with a fixed-key-derived value, which offered no key agreement or authentication and produced false assurance. This entry point now fails closed. Use the real Noise protocol implementation in security/crypto/protocols/ noise_protocol_extended.{h,c} (snepx_noise_handshake_init / snepx_noise_handshake_write_message) for an actual handshake.

Parameters
ts[out] Ts value (unused).
prologue[in] Prologue value (unused).
prologue_len[in] Prologue Len value (unused).
handshake_msg[out] Handshake Msg value (unused).
Returns
always -1 (unsupported).
