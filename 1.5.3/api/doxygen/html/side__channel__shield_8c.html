Perform Hsm Verify Measurement.

No TEE/HSM measurement source is available to this reference shim, so an attestation cannot be verified. Previously this returned success for any non-empty input, which produced false assurance. It now fails closed; use a platform attestation service (SGX/TDX/SEV quote verification) instead.

Parameters
expected[in] Expected value (unused).
len[in] Len value (unused).
